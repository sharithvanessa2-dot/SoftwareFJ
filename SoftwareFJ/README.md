
# SOFTWARE FJ
## Sistema Integral de Gestión de Clientes, Servicios y Reservas

### 1. Descripción del proyecto

Software FJ es una aplicación desarrollada en Python mediante el paradigma de programación orientada a objetos.

Su finalidad es gestionar clientes, servicios y reservas para una empresa que ofrece reservas de salas, alquiler de equipos y asesorías especializadas.

El sistema funciona sin utilizar bases de datos. La información se administra mediante objetos y listas internas, mientras que los archivos de registro permiten almacenar eventos y errores.

### 2. Objetivo general

Desarrollar un sistema integral que aplique los principios de programación orientada a objetos, incorporando mecanismos de validación, manejo de excepciones y registro de errores para garantizar su estabilidad y funcionamiento.

### 3. Tecnologías utilizadas

- Lenguaje de programación: Python.
- Entorno de desarrollo: Visual Studio Code.
- Control de versiones: Git.
- Repositorio remoto: GitHub.
- Paradigma: Programación orientada a objetos.

### 4. Funcionalidades principales

- Registro y administración de clientes.
- Gestión de servicios especializados.
- Reservas de salas.
- Alquiler de equipos.
- Asesorías especializadas.
- Confirmación y cancelación de reservas.
- Cálculo de costos, impuestos y descuentos.
- Validación de datos.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores mediante archivos de logs.

### 5. Conceptos de programación orientada a objetos

El proyecto implementa los siguientes conceptos:

- Abstracción.
- Herencia.
- Encapsulamiento.
- Polimorfismo.
- Sobrecarga de métodos.
- Manejo de excepciones.
- Modularidad.

### 6. Organización del proyecto

El proyecto está dividido en módulos independientes que permiten mantener una estructura organizada y facilitar su mantenimiento.

### 7. Ejecución del programa

Para ejecutar el sistema se debe abrir la carpeta del proyecto en Visual Studio Code y ejecutar el siguiente comando desde la terminal:

```bash
py main.py
```

### 8. Almacenamiento de información

El sistema no utiliza motores de bases de datos. La información se administra mediante estructuras de datos en memoria y los archivos de registro se utilizan para almacenar eventos y errores.

### 9. Autores

Proyecto académico desarrollado colaborativamente por estudiantes de programación.

### 10. Estado del proyecto

Proyecto en desarrollo y proceso de validación funcional.
